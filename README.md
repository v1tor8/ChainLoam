# ChainLoam

ChainLoam is a high-performance data pipeline manager that enables real-time load balancing and auto-scaling for concurrent system processing.

ChainLoam is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/ChainLoam.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure ChainLoam, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
